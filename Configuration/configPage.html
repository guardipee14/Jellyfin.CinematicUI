Cinematic UI

v0.1.12 · Jellyfin 12.1

One plugin for the cinematic profile login, Plex-inspired global theme, navigation cleanup, and rotating library-driven Home hero.

Library access stays under Jellyfin Users. Navigation hiding below is cosmetic only and does not grant or revoke access to any library.

Appearance

Controls the injected web layer and the global interface theme.

Adds a desktop library sidebar, spaced posters, and left-aligned captions. Smaller screens keep Jellyfin navigation.
Uses a slim timeline and compact controls while retaining Jellyfin playback, audio, subtitles, fullscreen, and automatic control hiding.
Uses smaller posters, clear Play actions, a subdued backdrop, and a season episode grid. Library navigation follows the library layout setting.
Keeps Jellyfin account and sign-out controls with compact spacing and the configured accent.

Login

Profile-forward sign-in experience using your Jellyfin splash artwork.

Home Hero

Controls which titles can be featured and how the carousel behaves.

Named libraries must match libraries available to the current user. No matches keeps the native Home page. Leave blank to use all available movie and TV libraries.
Optional. Matching is case-insensitive and only affects the hero carousel.

Navigation & Home Rows

Declutters the Web interface without changing Jellyfin library permissions.

Cosmetic only. A profile can still access any library allowed under Dashboard → Users. Leave blank when you want all permitted libraries visible.

Repository

Add this URL under Dashboard → Plugins → Repositories to install Cinematic UI and receive compatible releases through Jellyfin's Update Plugins task.

https://raw.githubusercontent.com/guardipee14/Jellyfin.CinematicUI/repository/manifest.json

Existing manual installations use the same plugin GUID and configuration file. Restart Jellyfin when it requests activation of an installed update.
