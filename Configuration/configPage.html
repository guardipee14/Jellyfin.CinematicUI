Cinematic UI

v0.1.5 · Jellyfin 12.1

One plugin for the cinematic profile login, Plex-inspired global theme, navigation cleanup, and rotating library-driven Home hero.

Library access stays under Jellyfin Users. Navigation hiding below is cosmetic only and does not grant or revoke access to any library.

Appearance

Controls the injected web layer and the global interface theme.

Login

Profile-forward sign-in experience using your Jellyfin splash artwork.

Home Hero

Controls which titles can be featured and how the carousel behaves.

If these user-visible libraries are found, the hero stays inside them and does not fall back to unrelated libraries.
Optional. Matching is case-insensitive and only affects the hero carousel.

Navigation & Home Rows

Declutters the Web interface without changing Jellyfin library permissions.

Cosmetic only. A profile can still access any library allowed under Dashboard → Users. Leave blank when you want all permitted libraries visible.

Repository

v0.1.5 includes repository-ready release files. Once the GitHub repository is published, add this URL under Dashboard → Plugins → Repositories.

https://github.com/guardipee14/Jellyfin.CinematicUI/releases/latest/download/manifest.json

Until that URL exists publicly, manual TrueNAS installs continue to work normally and Jellyfin may show repository metadata as Unknown.
